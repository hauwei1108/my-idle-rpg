# Google 雲端優先與訪客本機存檔

## 規則

- 訪客只使用本機遊戲進度，不存入 Supabase。
- Google 登入：先取得獨佔遊戲連線，下載該帳號的 Supabase JSON，套用到本機快取，再開始遊戲。雲端進度為主。
- Google 帳號已有進度：無論本機是否有角色或 NPC 資料，登入後都優先載入雲端進度。無需手動點下載。
- Google 帳號沒有進度：清空不屬於此帳號的本機遊戲鍵後，允許創角或匯入原格式 JSON；首次成功存檔即自動綁定帳號。
- 訪客切換 Google：只要本機已有訪客角色或共用資產，在 Google OAuth 前跳出警告，請玩家先在遊戲匯出原來的角色進度 JSON。取消表示繼續訪客模式；確認才跳轉 Google 登入。訪客進度不會自動帶入 Google。
- Google 登出：先確認本機最新進度已上傳；失敗不登出。登出成功後清除 Google 本機快取並重載，避免訪客讀到另一帳號的角色。
- Google 雲端查詢失敗時，禁止以舊本機資料進入 Google 角色。
- 持續使用每 10 秒雲端同步、後登入踢前、RPC 身分／session／revision 驗證；資料庫與 JSON 格式均無變更。

## 實作

使用 js/33-google-auth.js 提示切換模式；js/34-cloud-save.js 在登入時自動讀雲端並還原，不再讓本機是否有資料決定能否下載。使用短期 tab sessionStorage 標記避免還原後重新整理時無限循環。

**限制：** 如果訪客在警告後仍未匯出，訪客角色被雲端或空白進度覆蓋後，該本機進度可能無法回復。網路斷線或瀏覽器意外終止之前尚未完成同步的進度，也不保證已在雲端。

資料庫不需要新的 SQL migration；沿用 game_saves、game_sessions 及原有 RPC。
